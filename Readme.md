# Clickjacking Detection System

## Project Description

This is a basic Clickjacking Detection System developed using HTML, CSS and JavaScript.

The project demonstrates how a website can detect whether it is being loaded inside an iframe.

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Jenkins

## Features

- Clickjacking detection
- iframe detection
- Simple user interface
- Automated testing using Node.js
- Jenkins CI pipeline

## Testing

The project contains 10 automated test cases.

The tests check:

1. index.html file exists
2. Readme.md file exists
3. HTML tag exists
4. Head tag exists
5. Body tag exists
6. Closing HTML tag exists
7. Title tag exists
8. HTML file is not empty
9. Readme file is not empty
10. Closing body tag exists

## Running Tests

Run the following command:

```bash
node test.js
